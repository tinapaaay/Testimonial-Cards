# Testimonial Cards

A responsive testimonial cards component built with HTML and CSS.

This project displays different testimonial-card layouts, including dark cards, bordered cards, image cards, and a large featured testimonial. It is based on the [Testimonial Cards project from roadmap.sh](https://roadmap.sh/projects/testimonial-cards).

## Features

- Multiple testimonial card layouts
- Responsive two-column desktop grid
- Centered featured card on the second row
- Mobile-friendly one-column layout
- Profile images, ratings, names, and roles
- Dark and light card styles

## Built With

- HTML5
- CSS3

## What I Practiced

- CSS Grid
- Flexbox
- Responsive design with media queries
- CSS positioning
- Card layouts
- Image sizing with `object-fit`
- CSS variables
